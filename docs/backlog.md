# Backlog

这里记录不属于当前 `v0.2` 短期目标、但未来可能实现的想法。当前版本的详细范围见 [产品迭代路线](product-roadmap.md)。

记录在这里不代表承诺实现。每次只在上一版本验收完成后选择少量条目进入下一版本，避免为了远期设想扩大当前课程。

## 日常使用能力

- 笔记搜索
- 分页或增量加载
- 未保存提醒
- 标签和笔记本
- Markdown、PDF 等外部资料导入
- 基础移动端适配

## AI 交互与检索

- SSE 流式回答
- 保存多轮对话历史
- 重新生成和复制回答
- 向量检索与关键词检索融合
- Reranker 重排序
- 检索和回答质量评测
- Agent 工具调用
- 写操作前的用户确认

## 安全与可靠性

- 修改和重置密码
- 登录限流
- 更完整的令牌生命周期策略
- 安全响应头和审计日志
- 数据库备份与恢复演练
- 浏览器端到端测试

基础安全不属于可推迟的 backlog：密码哈希、服务端权限检查、用户数据隔离、基本输入校验和密钥隔离必须随当前功能保持有效。

## 性能与架构

- 根据查询计划增加数据库索引
- 缓存高频且适合缓存的数据
- 将确实耗时的任务改为异步执行
- 在真实容量需求出现后评估服务拆分

性能条目只有在出现真实数据量、可复现瓶颈或测量证据后才进入课程。

## 精细体验

- 深色模式
- 主题定制
- 复杂动画和过渡
- 更完整的设计系统
- 管理与质量分析面板
