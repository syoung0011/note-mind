# NoteMind 课程路线

这套课程以“完成产品”为主线，不追求一次讲完所有技术细节。

每节课只使用一个课程文件。课程进入“分析与分工”时创建该文件，随后随着讲解、亲手实现、检查整改和验收动态更新，验收通过后再补全总结并定档。
