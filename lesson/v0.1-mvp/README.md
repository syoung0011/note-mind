# NoteMind v0.1 MVP 课程

本目录保存 NoteMind 从零完成 MVP 的 17 节课程，课程均已验收完成。

这一阶段完成了 FastAPI、Vue、PostgreSQL、用户认证、笔记 CRUD、RAG 问答、Docker Compose、测试与部署。对应的正式代码快照使用 Git 标签 `v0.1.0` 固定；本目录用于保存学习过程和复习材料。

后续课程不会回写本版本的功能范围。发现确有必要修正文档错误时，应单独提交并说明原因。
