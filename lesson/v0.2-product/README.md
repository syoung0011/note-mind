# NoteMind v0.2 产品化迭代课程

## 版本目标

在不扩大 AI 能力范围的前提下，把已经能运行的 MVP 改造成普通用户可以独立完成注册、登录、记录笔记和提问的基础产品。

本版本优先解决主流程缺口、页面结构和基础反馈。只实现随当前功能即可完成的基础安全措施；复杂安全加固、数据库索引和其他性能优化暂不进入本版本。

## 版本完成标准

- 新用户不借助 Swagger 即可注册、登录和退出。
- 页面具有清晰、统一的导航、内容区和基础视觉规范。
- 笔记列表、编辑区与 AI 问答区的关系清楚。
- 加载、空数据、成功和失败都有基本反馈。
- 原有用户隔离、权限校验、密码哈希和密钥隔离不被破坏。
- 后端测试、前端构建和 Compose 配置检查通过。
- 功能通过短期分支开发和合并，最终发布 `v0.2.0`。

## 暂不进入本版本

- 数据库索引、缓存、异步任务等性能优化。
- 限流、审计、刷新令牌、完整安全响应头等系统性安全加固。
- SSE 流式回答、对话历史、混合检索和 Reranker。
- 标签、笔记本、文件导入、深色模式和复杂动画。
